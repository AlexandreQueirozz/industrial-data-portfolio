# 🏭 Industrial Data Analyst Portfolio & OEE Pipeline

End-to-end industrial data analytics project designed to optimize operational efficiency, monitor Overall Equipment Effectiveness (OEE), and support executive decision-making in the manufacturing sector.

---

## 📊 Project Overview
This project simulates an industrial data architecture, starting from raw database generation and ETL processing, up to an interactive executive dashboard built in Power BI.

### Key Features:
- **Python ETL Pipeline:** Automated scripts to generate, clean, and load industrial telemetry and maintenance data.
- **Relational Database:** Structured database storing machine telemetry, downtime logs, production orders, and maintenance costs.
- **Power BI Dashboard (3 Pages):**
  1. *Global Availability (OEE)* & Key Performance Indicators.
  2. *Historical Production Trend* & Output Analysis.
  3. *Downtime Breakdown & Cost Distribution* for loss accounting.

---

## 🛠️ Tech Stack & Tools
- **Python:** Data manipulation and ETL automation.
- **SQL / Relational Database:** Data structuring and storage.
- **Power BI:** Data visualization, DAX modeling, and UI/UX report polish.
- **Git & GitHub:** Version control and portfolio sharing.
